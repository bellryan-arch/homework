Parent controls & progress

Math practice with a parent dashboard—not another complicated account

Bell's gives parents control over how practice progresses while keeping the learner experience simple. The current version stores progress in the browser and includes backup tools in the Parent Dashboard.

What parents can control

Mastery threshold

Choose the percentage used to determine mastery.

Completion threshold

Set the score used to treat a practice page as completed.

Minimum pages

Control the minimum number of pages a learner should complete at a level.

Auto-advance

Decide whether the current level moves forward automatically after mastery.

Solution access

Choose whether the learner can reveal solutions during practice mode.

Require all answers

Optionally require every question to be answered before checking.

What the dashboard shows

The Parent Dashboard includes a summary, skill mastery and recent practice pages. It also includes export, download, import and reset tools so a parent can keep a backup of the browser-local data.

Frequently asked questions

Does it require a parent account?

No. This published version uses a parent access password inside the browser rather than a hosted account system.

Can progress move between devices?

Not automatically in this version. Progress is browser-local, but the Parent Dashboard includes export/download and import tools for backups.

Ready to practice?

Open Bell's Math Practice, choose a level, question count and focus, and start a practice page. No student account is required for this browser-local version.
