Browser-local by design

Privacy and data in Bell's Math Practice

The current published Math Practice version is a single-child browser app. It does not require a student account and its footer states that progress is saved in this browser only.

Start free math practiceFor parents

Where progress is stored

Practice progress is stored locally in the browser used for Math Practice. That means progress does not automatically follow the learner to a different browser or device.

Backups

The Parent Dashboard includes export, download and import controls. Use those tools if you want to keep a copy of the locally stored data or restore it later.

Clearing browser data

Because progress is local to the browser, clearing site/browser storage can remove local progress. Keep a downloaded backup if the history matters to you.

Accounts and syncing

This version does not provide automatic cloud syncing between devices. If Bell's adds an account or cloud-sync feature later, this page should be updated before that version is promoted.

Ready to practice?

Open Bell's Math Practice, choose a level, question count and focus, and start a practice page. No student account is required for this browser-local version.
